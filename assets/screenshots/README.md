이 폴더는 각 실습 문서에서 참조하는 **스크린샷 이미지**를 담습니다. 문서에는 먼저 플레이스홀더와
"📸 캡처 안내" 캡션만 들어가 있고, 실제 이미지는 아래 규칙에 따라 촬영해 채웁니다.

## 촬영 환경
- **워크스페이스 프로필**: `coupang-appdemo`
- **URL**: `https://fe-sandbox-stefano-coupang-appdemo.cloud.databricks.com`
- 브라우저 확대 배율 **100%**, 창 폭 **약 1440px** 권장(초심자가 메뉴를 알아보기 쉽게).
- 다크/라이트 테마 중 **하나로 통일**(권장: 라이트).

자동 캡처를 진행할 경우에도 위 파일명 규칙을 그대로 사용합니다.
