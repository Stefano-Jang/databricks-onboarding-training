Databricks 소개 ① 설립·연혁

2013년 UC Berkeley AMPLab의 Apache Spark 창시자 7인
(Ali Ghodsi · Matei Zaharia · Ion Stoica · Reynold Xin · Patrick Wendell 외)이 창업

  • 2009Apache Spark 프로젝트 시작 (UC Berkeley AMPLab)
  • 2013Databricks 창업
  • 2018MLflow 오픈소스 공개 — ML 실험 추적 표준화
  • 2019Delta Lake 오픈소스 공개 — ACID 트랜잭션 레이크
  • 2020'레이크하우스' 아키텍처 개념 제창 · Redash 인수 — SQL 시각화·대시보드(→ Databricks SQL 대시보드 기반)
  • 2021Unity Catalog · Databricks SQL 출시
  • 2023MosaicML 인수(~$1.3B) — 생성형 AI/LLM(→ Mosaic AI)
  • 2024DBRX 공개 · Unity Catalog 오픈소스화 · AI/BI(Genie) 출시 · Tabular 인수($1B+) — Apache Iceberg 창시자들의 회사(Delta·Iceberg 통합)
  • 2025Lakebase · Agent Bricks · Databricks One · Neon 인수(~$1B) — 서버리스 Postgres(→ Lakebase)
  • 2026Panther 인수 — AI 보안 SOC 플랫폼(→ Lakewatch 보안 레이크하우스) · Gartner AI/DSML Platforms MQ Leader

레이크하우스 = 데이터 레이크의 저렴함 + 웨어하우스의 편리함을 개방형 저장소 하나로 통합

Spark 창시자들이 직접 만든 회사임을 강조하세요. 레이크하우스 정의는 이후 실습 전반에 반복해서 언급할 핵심 개념입니다.

Databricks 소개 ③ Gartner Magic Quadrant

Databricks = Leader (2년 연속 highest execution + furthest vision)

출처: Gartner, Magic Quadrant for AI Platforms for Data Science and Machine Learning (2026년 6월) — Databricks 블로그 인용. Databricks는 Leaders 사분면에서 2년 연속 실행력 최상·비전 최우로 평가.

Gartner MQ의 4분면(가로축=비전 완성도, 세로축=실행력) 개념을 간략히 설명하세요. AI Platforms for Data Science and ML 부문에서 Databricks가 Leaders 사분면에 2년 연속(실행력 최상·비전 최우) 선정된 점이 엔터프라이즈 신뢰성의 지표임을 강조하세요.

06

테이블·Volume·RBAC/ABAC

  • Unity Catalog 3레벨 네임스페이스: catalog.schema.table
  • GRANT/REVOKE로 오브젝트별 권한 부여
  • Volume — 파일(비정형 데이터) 저장 관리 단위
  • 행 필터(Row Filter) · 열 마스킹(Column Masking) — ABAC 구현
📄 GitHub 튜토리얼 docs/06-tables-volumes-rbac-abac.md
Unity Catalog의 계층 구조를 칠판이나 슬라이드 그림으로 먼저 보여 주면 이해가 빠릅니다. 열 마스킹은 개인정보 보호 시나리오로 설명하면 실감납니다.

Databricks vs Snowflake — 벤치마크 (공정하게 읽기)

① TPC-DI ETL 벤치마크 (2025년 6월, 공개) — Databricks SQL Serverless 기준

Snowflake Gen2 대비 (SF10000 ≈ 1TB · Azure · dbt Core · 막대가 짧을수록 우수)

속도 · DBX
1.0× (기준)
속도 · SF
2.8× 느림
비용 · DBX
1.0× (기준)
비용 · SF
3.6× 비쌈

Gen1 대비 4.3× 빠름·4.1× 저렴. ⚠ Databricks 자체 공개 벤치마크(자사 유리) · 커뮤니티 피드백 반영. 출처: DBSQL SME Engineering (Medium, 2025-06).

② 독립 제3자 (중립)

  • Fivetran·Brooklyn Data (2022, 1TB TPC-DS) — 동등 구성 시 거의 대등
  • → 출처·워크로드에 따라 결과가 달라짐

③ Databricks 공식 기록

  • TPC-DS 100TB 세계 기록 (TPC 공식 감사, 32.9M QphDS)
  • Snowflake는 공식 TPC-DS 결과 미제출

벤치마크는 워크로드·구성에 따라 크게 달라집니다. ①의 TPC-DI 수치는 Databricks 엔지니어링 팀이 발표한 공개 벤치마크(자사에 유리, 커뮤니티 피드백 반영본)이며, 중립 제3자(②)에서는 거의 대등했습니다. 실제 의사결정 전 반드시 자체 워크로드로 직접 측정하세요.

한쪽으로 단정하지 말 것 — "구성·워크로드에 따라 결과가 달라진다"를 강조하고, ①은 Databricks 자체 발표라 자사 유리함을 밝히세요. 출처 URL — ① TPC-DI(2025-06, DBSQL SME Engineering): https://medium.com/dbsql-sme-engineering/benchmarking-etl-with-the-tpc-di-snowflake-cb0a83aaad5b · ② 독립 제3자(Fivetran/Brooklyn Data): https://www.fivetran.com/blog/warehouse-benchmark · ③ TPC-DS 세계기록: https://www.databricks.com/blog/2021/11/02/databricks-sets-official-data-warehousing-performance-record.html
