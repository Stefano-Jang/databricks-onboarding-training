Databricks 소개 ① 설립·연혁

2013년 UC Berkeley AMPLab의 Apache Spark 창시자 7인
(Ali Ghodsi · Matei Zaharia · Ion Stoica · Reynold Xin · Patrick Wendell 외)이 창업

  • 2009Apache Spark 프로젝트 시작 (UC Berkeley AMPLab)
  • 2013Databricks 창업
  • 2018MLflow 오픈소스 공개 — ML 실험 추적 표준화
  • 2019Delta Lake 오픈소스 공개 — ACID 트랜잭션 레이크
  • 2020'레이크하우스' 아키텍처 개념 제창
  • 2021Unity Catalog · Databricks SQL 출시
  • 2023MosaicML 인수 (~$1.3B) — 기업용 LLM 훈련 역량 확보
  • 2024DBRX 공개 · Unity Catalog 오픈소스화 · AI/BI (Genie) 출시
  • 2025Lakebase · Agent Bricks · Databricks One · Neon 인수 (~$1B)

레이크하우스 = 데이터 레이크의 저렴함 + 웨어하우스의 편리함을 개방형 저장소 하나로 통합

Spark 창시자들이 직접 만든 회사임을 강조하세요. 레이크하우스 정의는 이후 실습 전반에 반복해서 언급할 핵심 개념입니다.

03

관리자 역할

  • 계정 Admin — 전체 계정·워크스페이스 생성·삭제
  • 메타스토어 Admin — Unity Catalog 오브젝트 최상위 관리
  • 워크스페이스 Admin — 단일 워크스페이스 사용자·설정 관리

세 가지 Admin 역할을 실수로 혼동하는 경우가 많습니다. 계정 Admin은 신중하게 부여해야 함을 강조하세요.

그룹 관리

  • 그룹 생성 및 사용자 일괄 추가
  • 관리자 권한 위임 — 그룹 단위 역할 부여
  • 최소 권한 원칙: 개인 대신 그룹에 권한 부여 권장

실제 운영 환경에서는 개인 계정에 직접 권한을 주기보다 그룹을 사용해야 관리가 편리하다는 점을 사례로 설명하세요.
05

컴퓨트 유형

  • All-Purpose Cluster — 개발·탐색용, 시간 단위 과금
  • SQL Warehouse — BI·SQL 워크로드 특화, 동시성 우수
  • 서버리스(Serverless) — 즉시 시작, 인프라 관리 불필요
  • 용도별 올바른 컴퓨트 선택 기준 및 비용 비교
📄 GitHub 튜토리얼 docs/05-compute.md
컴퓨트 선택이 비용에 직결됨을 강조하세요. 서버리스는 시작 시간이 거의 없어 소규모 작업에 유리하다는 점을 데모로 보여 주면 효과적입니다.
06

테이블·Volume·RBAC/ABAC

  • Unity Catalog 3레벨 네임스페이스: catalog.schema.table
  • GRANT/REVOKE로 오브젝트별 권한 부여
  • Volume — 파일(비정형 데이터) 저장 관리 단위
  • 행 필터(Row Filter) · 열 마스킹(Column Masking) — ABAC 구현
📄 GitHub 튜토리얼 docs/06-tables-volumes-rbac-abac.md
Unity Catalog의 계층 구조를 칠판이나 슬라이드 그림으로 먼저 보여 주면 이해가 빠릅니다. 열 마스킹은 개인정보 보호 시나리오로 설명하면 실감납니다.
07

노트북 & S3 데이터 읽기

  • 노트북 생성 및 Python/SQL 셀 실행
  • External Location을 통해 S3 버킷 데이터 읽기
  • DataFrame API로 Delta 테이블 생성 및 조회
  • 노트북 협업(공유·주석) 기능 소개
📄 GitHub 튜토리얼 docs/07-notebooks.md
실제 S3 버킷을 미리 준비해 두고 데모 중 직접 파일을 읽는 모습을 보여 주세요. 에러가 날 경우를 대비해 샘플 데이터를 Unity Catalog 볼륨에도 복사해 두세요.
07b

Lakeflow Connect: S3 데이터 가져오기

  • 코드 없이 UI로 S3 파일을 Unity Catalog 테이블로 적재
  • Add data → Databricks connectors → Amazon S3
  • External Location(+Storage Credential) 기반 안전한 접근
  • 미리보기 후 카탈로그·스키마·테이블 지정하여 생성
📄 GitHub 튜토리얼 docs/07b-lakeflow-connect-s3.md
07번(노트북 코드로 읽기)과 대비해, 코드 없이 관리형 UI로 테이블을 만드는 방법임을 강조하세요. 고객 환경에서는 대상 S3 버킷에 대한 Unity Catalog External Location이 미리 준비돼 있어야 합니다.
08

SQL 편집기 & 스니펫

  • SQL 편집기에서 쿼리 작성·실행·결과 시각화
  • 쿼리 저장 및 팀 공유
  • 스니펫(Snippets) 등록 — 자주 쓰는 SQL 템플릿 재사용
  • 쿼리 히스토리 및 실행 계획(EXPLAIN) 확인
📄 GitHub 튜토리얼 docs/08-sql.md
스니펫은 팀 표준 쿼리를 공유하는 데 매우 유용합니다. 실습 중 수강생이 직접 스니펫을 만들어 보게 하면 기억에 남습니다.
